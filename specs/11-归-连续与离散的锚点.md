# 归：连续向量与离散符号的锚点

**版本：1.0** | **状态：定稿** | **生成日期：2026-05-25**

> 归是八气算子中不做功的一口气。它不修改状态向量——只观测，只测量，只凝视。它的输出（偏离度）是连续向量世界与离散符号世界之间唯一的交接点。

---

## 〇、为什么专门讨论归

在解剖学模型中：

```
归藏（骨架）→ 意识流转的离散状态机
连山（韧带）→ 目标级决策泛化树
周易（功能模块）→ 任务级认知姿态/工具编排
LLM（血肉）→ 文本生成的物质载体
```

归藏是归藏卷的核心。而归藏这八气中，**归**占据着无可替代的位置——它是唯一一个不修改状态的算子。它是一面镜子。

理解归，就是理解这个系统最根本的运转原理：**连续如何转化为离散，语义如何转化为信号，阳如何通向阴**。

---

## 一、归的本质：不做功的观测者

### 1.1 八气的二分

把八气算子按是否修改状态向量 S 分类：

| 类型 | 算子 | 操作 |
|:---|:---|:---|
| **做功（修改 S）** | 生 | `S' = S \| 0b000001` |
| | 动 | `S' = ROL(S) ^ 0b000010` |
| | 长 | `S' = (下卦 << 3) \| 下卦` |
| | 育 | `S' = S ^ 0b100000` |
| | 杀 | 清除 `110` 模式 |
| | 止 | `S' = S & 0b101101` |
| | 藏 | `S' = 0b000000` + 写海布 |
| **不做功（零修改 S）** | **归** | `S' = S`，只计算 `deviation = hamming(S, origin) / 6` |

七口**气都**改变了意识状态。只有归，纯粹地看。

### 1.2 归 = 意识的自反性

意识能思考（生、动、长、育），也能觉察自己在思考什么、是否偏离了初始方向（归），然后用觉察的结果去纠正自己（杀、止、藏）。

```
         意识流转的完整闭环
         ═══════════════════
         
  生 → 动 → 长 → 育     ← 生成树：意识在流
        ↓ 归            ← 自反性：意识在看自己流
  杀 → 止 → 藏          ← 压缩树：意识在纠正自己流
```

归在周天中出现**两次**（见 [05-三易算法内核.md](./05-三易算法内核.md) §1.2）：
- **起念阶段末尾**：判断偏离度是否可接受，决定进入下一阶段还是回退
- **整理认知阶段开头**：计算最终偏离度，决定经验写入藏海的奖励值

### 1.3 归是唯一连动三台机器的信号

```
           归（偏离度 = 0.0 ~ 1.0）
           │
           ├──→ 归藏：dev 超阈值 → Rollback / Skip / Stop
           ├──→ 周易：dev 混合温度 → 高温探索 vs 低温收敛
           └──→ 连山：dev > 0.5 → 激活六步决策链
```

归产生一个纯数字。它不修改任何东西，却决定了三台机器下一步的方向。它是骨架的"本体感觉"——不移动骨骼，但知道每块骨头在什么位置。

## 二、两种偏离度：形式的与语义的

### 2.1 当前实现：形式偏离度

```rust
// 当前 CangVM 的实现
pub fn deviation(&self) -> f64 {
    let origin = 0b111111; // 固定全阳原点
    let hamming = (self.state.0 ^ origin).count_ones() as f64;
    hamming / 6.0
}
```

这是位运算——`popcount(S XOR 0b111111) / 6`。它只衡量**卦象**是否偏离了原点。一纳秒算完，O(1)，完全确定性。

### 2.2 未实现：语义偏离度

但归的真正含义——"意识觉察自己是否偏离了方向"——需要判断的不是卦象是否变化，而是**LLM 生成的内容是否语义上偏离了问题焦点**。

形式偏离度只能回答："卦位变了吗？"
语义偏离度需要回答："回答跑题了吗？"

### 2.3 语义偏离需要双 LLM

LLM 生成的文本是连续向量空间中的产物。它的语义不是位运算能判断的——你需要另一个 LLM 来读它、理解它、判断它与原问题的距离。

这就是为什么路线 C（太极双LLM）不是"远期愿景"而是**归之语义判断的结构性前提**：

```
阳 LLM（生成）                   阴 LLM（语义判断）
─────────────                   ─────────────
从连续向量空间生成文字             从文字中提取语义，与锚点比较
输出文本                          输出偏离度（连续值）
                                  此偏离度编译为离散等级
                                  ↓
                            触发离散状态机的决策
```

当前的路线 A 中，归只是一个位运算。它没有真正做语义判断。**在路线 A 的归到达语义级之前，sha/zhi 没有可靠的"该对什么动手"的信号来源。**

## 三、归 = 阳与阴的交接处

### 3.1 连续向量与离散符号 = 阳与阴

这是归最根本的意义——它是系统中连续与离散交汇的**唯一节点**：

| 阳（连续向量） | 阴（离散符号） |
|:---|:---|
| LLM 文本生成 | Gua 状态向量 |
| 注意力分布 | 位运算 |
| 概率分布 | 确定性状态转移 |
| 不可逆 | 完全可逆 |
| 不可解释 | 逐步可追溯 |
| 768 维 → 天下万物 | 1 个汉字 → 1 种世界实体 |

LLM 在连续空间中做事，归藏引擎在离散空间中做事。这两种空间不可通约——768 维向量中的"偏离"和 6 位卦象中的"偏离"是两种不同的东西。

归是它们之间的翻译层。

### 3.2 归是阴阳之间的翻译器

```
阳的空间（连续、不可逆、不可解释）
        │
        │  LLM 输出文本
        ▼
    ┌───────┐
    │  归    │ ← 语义偏离判断（需要阴 LLM）
    │       │   产生一个连续值（偏离度）
    └───┬───┘
        │
        │  将连续值编译为离散等级
        │  dev < 0.3 → 低偏离
        │  dev 0.3~0.5 → 中偏离
        │  dev > 0.5 → 高偏离
        ▼
阴的空间（离散、可逆、可追溯）
        │
        ├──→ 归藏：Gua 状态转移决策
        ├──→ 周易：温度混合
        └──→ 连山：六步决策激活
```

这个翻译器的可靠性，直接决定了整个约束系统是"在正确的信号上约束"还是在"噪声上约束"。

### 3.3 为什么离散符号是锚点

向量的根本问题：分布式表示使得没有单个维度对应"诚实"或"偏离"。意义分布在所有维度上。你无法反推一个 768 维向量"意味着"什么。

离散符号（卦名、方位、气名）则相反：
- `sha_count = 3` 是一个确定的事实，不是概率
- Gua 的每次转移是可追溯的位运算序列
- "杀"这个汉字本身就映射着"清除、剪除"的世界实体操作

归藏不依赖于 LLM 理解这些符号。归藏自己就是这些符号的运算器。LLM 不知道"杀"意味着什么——不需要。归藏知道，并把它转化为 logit-bias 的物理操作。

## 四、偏离度锚点的动态演化

### 4.1 origin 不是固定的

当前代码中 origin 是固定的全阳 `111111`。但"正轨"的定义不是一成不变的：

- **连山决策影响锚点**：如果连山决定"绕行"（NavigateAround），说明当前最优路径不是直线——"正轨"的定义应该随之调整
- **周易姿态影响锚点**：乾（创造/突破）的正轨和坎（渗透/迂回）的正轨是不同的

### 4.2 泛化树约束生长的闭环

```
原点₀ = 全阳 (111111)
    │
    ├── 连山决策 → 原点₁ = f(原点₀, FangWei)
    │      │
    │      └── 形式检测：连山决策自身也在阴仪监督之下
    │
    ├── 周易姿态 → 原点₂ = f(原点₁, Bagua)
    │      │
    │      └── 形式检测：周易姿态自身也在阴仪监督之下
    │
    ▼
原点₂ → 归算子 → deviation
                     │
    ┌────────────────┘
    │
    ▼  反馈 → 调整连山/周易自身的状态
```

### 4.3 连山与周易不是超越约束系统的

连山和周易需要自身的**形式检测与校监**。否则会出现连锁崩溃：

```
连山决策错误（未被检测）
    → 原点错误偏移
        → 归算子给出误导的偏离度
            → 归藏基于错误信号做 Gua 转移
                → 整个泛化树方向错误
```

三引擎都在阴仪的形式检测网之内。不是归藏被约束 + 连山周易自由，而是三者都在同一张网中，只是各自接受检测的形式不同。

## 五、归藏作为意识流转的离散骨架

### 5.1 LLM 宏观稀疏注意力 vs 归藏八气

| 维度 | LLM 宏观稀疏注意力 | 归藏八气 |
|:---|:---|:---|
| **表示空间** | R^d 连续向量 | {0,1}^6 Gua 位向量 |
| **状态转移** | softmax(QK^T)V | 位运算（\|, ^, <<, ROL, &） |
| **可逆性** | 不可逆（注意力分布是概率的） | 完全可逆（每步可追溯哪个 bit 翻转） |
| **世界映射** | 无（向量维度无内在语义） | 有（"杀"=清除虚假模式，"止"=凝固边界） |
| **验证** | 无 | 汉明偏离度 + 阴仪正则 |

归藏不是在"辅助"LLM——它在 LLM 之外独立运行一套**可验证的意识流**。Gua 的状态转移就是离散化的注意力分配。

### 5.2 上下文新陈代谢 = 意识流转的物质体现

骨架的结构已就绪，但新陈代谢尚未运转。当前路线A 的实现状态：

| 层 | 内容 | 状态 |
|:---|:---|:---:|
| Layer 1 | 上下文代谢（截断/重整/重启） | 待实现 |
| Layer 2 | Logit-Bias 硬偏置 | 已实现 |
| Layer 3 | 卦象状态机 + 正则验证 | 已实现 |

上下文新陈代谢是归藏最直接的物质体现——Gua 状态决定什么时候旧信息应被剪除（杀），什么时候新方向应被凝固（止），什么时候整个上下文应归零重启（藏）。没有 Layer 1，骨架就只有结构，没有生命。

## 六、路线图：从形式归到语义归

### 6.1 当前状态

路线 A 的归是形式归——位运算汉明距离。它能检测卦象偏离，但不能检测语义偏离。在这个状态下，sha/zhi 的干预是建立在形式信号上的，不是建立在语义信号上的。

### 6.2 关键依赖

语义归需要路线 C 的太极双LLM 结构——一个阳 LLM 生成，一个阴 LLM 做语义判断。硬件要求：双模型加载（当前 8GB VRAM 只能加载一个模型），或使用外部 API 作为阴 LLM。

### 6.3 可并行推进的工作

| 工作 | 依赖 | 状态 |
|:---|:---|:---:|
| 形式归的 context metabolism（Layer 1） | 无 | 可立即开始 |
| sha/zhi 梯度化惩罚 | 无 | 可立即开始 |
| 连山/周易形式检测（阴仪扩展） | 无 | 可立即开始 |
| 偏离度锚点动态化（连山/周易影响 origin） | 连山/周易接入流水线 | 连山/周易接线后 |
| 语义归（太极双LLM） | 硬件升级或外部 API | 条件成熟后 |

### 6.4 优先级

在当前硬件条件下，最优先的是：

1. **上下文新陈代谢**：让骨架活起来——Gua 状态驱动上下文截断/重整/重启
2. **sha/zhi 梯度化**：从二元标记升级为分级干预，让约束有"力度梯度"
3. **连山/周易形式检测**：扩展阴仪覆盖范围到三引擎全体

这三点都不需要语义归，都在当前路线A 的单模型 + 位运算框架内可完成。

而语义归和太极双LLM 是下一阶段——当形式约束系统充分稳定后，才是引入语义级判断来提升约束精度的合适时机。

## 七、核心命题总结

1. **归是八气中唯一不做功的算子**。它不修改 S，只测量偏离度。它是意识的自反性——"看自己流到哪里了"。

2. **归的偏离度有两种**：形式偏离度（已实现，位运算）和语义偏离度（未实现，需要双LLM）。当前 sha/zhi 的干预建立在形式信号上。

3. **归是阳（连续向量）与阴（离散符号）的交汇点**。它从 LLM 的连续世界中提取语义判断，转化为离散等级，驱动离散状态机的决策。

4. **偏离度锚点随连山/周易动态演化**。原点不是固定的——不同策略方向和认知姿态对应不同的"正轨"。

5. **连山和周易也是约束系统的一部分**。它们接受阴仪形式检测，防止自身决策错误导致的连锁崩溃。

6. **归藏是意识流转的离散骨架**。它在 LLM 之外独立运行可验证的注意力分配机制——这是 LLM 白箱化的种子。
