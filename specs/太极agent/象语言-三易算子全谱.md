## 二、归藏八气算子（心之律）

### 位运算定义

```
状态空间：S ∈ {0..63} (6-bit)
元知觉向量：U = 111111 (默认)

生(S)  = S | 0b000001                                    // 木气
动(S)  = ((S << 1) | (S >> 5)) ^ 0b010 & 0b111111       // 风气
长(S)  = ((S & 0b111) << 3) | (S & 0b111)               // 火气
育(S)  = S ^ 0b100000                                    // 水气
杀(S)  = if (S & 0b111) == 110 → S & ~0b111             // 金气
         if ((S>>3) & 0b111) == 110 → S & ~0b111000
止(S)  = S & 0b101101                                    // 山气
归(S)  = S                     // 身份函数                // 天气
         + deviation = popcount(S ⊙ 111111) / 6          // 单独计算
藏(S)  = store(S, reward); S = 0                         // 地气
```

### 周天子序列

```
起念：   生 → 动 → 归
立目标： 长 → 育 → 杀 → 止
整理：   归 → 杀 → 藏
完整周天：生 → 动 → 归 → 长 → 育 → 杀 → 止 → 归 → 杀 → 藏
```

### 归藏象语言语法

```
生                            # 无参
动                            # 无参
长                            # 无参
育                            # 无参
杀 金                         # 带目标卦
止 101101                     # 带掩码
归                            # 无参（输出为偏离度变量）
藏 善                         # 带标签
藏 恶
```

## 三、连山六步算子（行之决）

### 决策链路

```
艮 → 气 → 甲 → 元 → 峙 → 决
```

| 步骤 | 算子 | 输入 | 输出 | 触发条件 |
|------|------|------|------|---------|
| 1 | 艮 | 当前任务列表 | 布尔（是否激活） | 任务数 ≥ 2 |
| 2 | 气 | 目标进度历史 | 阶段标签 | 艮=true |
| 3 | 甲 | 受阻次数 | 受阻级数 | 气已判断 |
| 4 | 元 | 最近感知时间 | 新鲜度 | 甲已判断 |
| 5 | 峙 | 经验模式 + 障碍日志 | 推力/阻力对 | 元已判断 |
| 6 | 决 | 峙的输出 | 方位决策枚举 | 峙已完成 |

### 六气（目标阶段）

```
春 → 启动期：目标初立，策略试探阶段
夏 → 盛长期：策略验证有效，全力推进
秋 → 收敛期：开始遇到边界，需收缩调整
冬 → 休眠期：严重受阻或资源耗尽
```

### 六甲（受阻级数）

```
初甲 → 首次受阻 → 建议 push_through（硬推穿越）
再甲 → 再次受阻 → 建议 navigate_around（绕行）
三甲 → 三次受阻 → 建议 decompose（分解目标）
```

### 三元（上下文新鲜度）

```
新 → 最近 1 轮内感知过 → 上下文可靠
陈 → 超过 3 轮未感知 → 需重新收集信息
```

### 七种方位决策

```
continue          # 维持现状，继续当前策略
push_through      # 硬推——决心穿越已知障碍
navigate_around   # 绕行——换路径达到同一目标
wait_gather       # 等待——先收集更多信息
decompose         # 分解——拆成更小子目标
escalate          # 升级——标记需外部介入
abort             # 放弃——彻底终止
```

### 连山象语言语法

```
艮
气 秋
甲 三
元 陈
峙:
    推力: "已有 12 条有效线索"
    阻力: "关键词命中率降至 5%"
决: navigate_around
```

## 四、周易八卦算子（知之姿）

### 八卦格栅矩阵

| 卦 | 二进制 | 五行 | 认知姿态 | LLM 温度 |
|----|--------|------|---------|---------|
| ☰ 乾 | 111 | 金 | 创造：突破创新 | 1.2（高温） |
| ☱ 兑 | 110 | 金 | 表达：输出交付 | 0.9 |
| ☲ 离 | 101 | 火 | 明照：审视反思 | 0.5（低温） |
| ☳ 震 | 100 | 木 | 启动：快速收集 | 1.0 |
| ☴ 巽 | 011 | 风 | 渗透：深度分析 | 0.7 |
| ☵ 坎 | 010 | 水 | 破局：突破障碍 | 1.1 |
| ☶ 艮 | 001 | 山 | 止定：收窄目标 | 0.3（极低温） |
| ☷ 坤 | 000 | 土 | 承载：稳定执行 | 0.6 |

### 五行生克全表

**相生（↓ 促进转换）：**
```
木(震001) → 火(离101)：  收集后自然评估
火(离101) → 土(坤000)：  审视后转向执行
土(坤000) → 金(兑110)：  积累后输出
金(兑110) → 水(坎010)：  输出后进入破局
水(坎010) → 木(震001)：  破局后需新信息
风(巽011) → 火(离101)：  渗透后需审视
山(艮001) → 土(坤000)：  收窄后转向积累
```

**相克（↓ 抑制转换）：**
```
兑(110) 克 震(001)：  过度输出抑制收集
离(101) 克 兑(110)：  持续审视延迟交付
坎(010) 克 离(101)：  过度破局中断反思
震(001) 克 艮(001)：  新信息淹没边界
坤(000) 克 坎(010)：  稳定执行回避风险
乾(111) 克 坤(000)：  过度创造打破稳定
```

### 周易象语言语法

```
姿 乾                      # 进入创造姿态
姿 坤                      # 进入承载姿态
姿 坎                      # 进入破局姿态

生克:                      # 生克转换声明
    乾 → 离                # 创造后需审视
    离 → 坤                # 审视后转向执行
    兑 克 震               # 输出抑制收集
```

## 五、三层交互协议

### 数据流

```
┌─────────────────────────────────────────────┐
│              象语言运行时调度                │
├─────────────┬─────────────┬─────────────────┤
│  周易格栅    │  连山思变    │   归藏意识       │
│  每轮触发    │  受阻触发    │   5 分钟后台      │
│             │             │                 │
│ 姿 → 系统   │ 艮→决 →     │ S → 偏离度 →    │
│ 提示词编织  │ TPN 策略    │ 藏海 Hebbian     │
│      ↓      │     ↓       │       ↓          │
│ 温度+格栅   │ 方位决策    │ 目标/蓝图审查     │
└──────┬──────┴──────┬──────┴────────┬────────┘
       │             │               │
       └─────────────┼───────────────┘
                     ▼
              TPN 六爻循环
              （明觉→织→阳→阴→行动→暗驱）
```

### 互操作示例

```
# 完整的三层约束程序片段

姿 乾                              # 周易：选定创造姿态
生                                 # 归藏：起念

# 执行任务...（TPN 六爻）           # 假设第 3 轮开始受阻

艮                                 # 连山：启动思变
气 秋                              # 目标进入收敛期
甲 再                              # 第二次受阻
元 新                              # 上下文仍新鲜
峙:
    推力: "创造姿态下前 2 轮均成功"
    阻力: "第 3 轮 API 返回 429"
决: navigate_around                # 绕行决策
姿 巽                              # 周易：切换到渗透姿态

# 继续执行...

归                                 # 归藏：检查偏离度
若 偏离度 > 0.5:
    杀 金
    藏 恶
否则:
    藏 善
```
