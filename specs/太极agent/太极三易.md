# 太极架构（VingoBot）项目完整思想总结

---

## 一、总纲：太极生两仪 —— TPN + DMN 双循环认知架构

太极架构的根本洞见是：**主流Agent框架只有"执行"（重复），没有"学习"（迭代）**。AutoGPT、LangGraph、CrewAI 等做完100个任务时，和做第1个任务时一样"聪明"——它们将执行和学习混在同一次LLM调用中，两个都做不好。

太极架构从神经科学（人脑DMN/TPN拮抗网络）和《易经》哲学汲取灵感，将认知系统拆分为两个独立的、异步运行的循环：

```
太极（认知系统整体）
  ├── TPN（Task-Positive Network，阳，前台）—— 六爻循环：任务推进
  └── DMN（Default Mode Network，阴，后台）—— 坤元意识循环：认知演化
```

**TPN 推动目标前进，DMN 驱动认知进化——双循环并行，互不阻塞，持续迭代。**

## 二、TPN 六爻架构思想：行动 + 反思的完整认知闭环

### 2.1 六爻不是六个步骤，是六个认知职责角色

六爻循环将一轮认知执行拆解为六个角色：

| 爻位 | 名称 | 核心职责 | 一句话 |
|------|------|---------|--------|
| 初爻 | **明觉**（Mingjue） | 感知者 + 思变决策 | "我在哪？下一步怎么办？" |
| 二爻 | **织**（Weaver） | 策略编织师 | "我该怎么思考？" |
| 三爻 | **阳**（Yang） | 执行意图提出者 | "我要做什么？" |
| 四爻 | **阴**（Yin） | 审批者 | "这安全合理吗？" |
| 五爻 | **行动**（Executor） | 实际执行者 | "做！" |
| 上爻 | **暗驱**（Anqu） | 深度反思者 + 路由决策 | "我学到了什么？" |

### 2.2 行动半环 + 反思半环 = 完整一轮

```
行动半环（改变世界）：明觉(含思变) → 织 → 阳 → 阴 → 行动
                                                ↓
反思半环（改变认知）：                          暗驱
                                                ↓
                                          下一轮明觉 ← 经验模式 + 路由决策
```

**每一轮都同时包含「行动」和「反思」两个不可分割的环节。** 行动产出"对世界的改变"（文件、API调用、搜索），反思产出"对认知的改变"（经验模式、路由决策）。

### 2.3 架构级硬约束：禁止连续两轮纯读

六爻架构强制每轮必须至少包含一个**可失败的写操作**——这是根本上防止Agent陷入"只读不做"死循环的架构级约束。纯读取不会产生DMN可学习的素材，也不会产生可验证的交付物。

### 2.4 三层决策体系

太极的决策不是单一节点的判断，而是分三层：
- **阳/阴**（轮次内）：执行意图 → 安全审批
- **暗驱路由决策**（目标级）：goal_next_task / goal_completed / goal_failed / continue_task
- **明觉思变决策**（策略级）：选择卦象、细化任务、评估进度

## 三、编织与思变：周易循环认知算法与连山循环认知算法

### 3.1 八卦认知格栅（L3层）—— 周易循环认知算法

八卦在太极架构中不是装饰，而是一个**8状态隐Markov认知调度引擎**：

```
☰ 乾 (创造) — 从0到1，突破创新
☷ 坤 (承载) — 稳定执行，积累成果
☳ 震 (启动) — 快速激发，广泛收集
☴ 巽 (渗透) — 深度潜入，细致分析
☵ 坎 (破局) — 面对风险，突破障碍
☲ 离 (明照) — 审视反思，照亮盲点
☶ 艮 (止定) — 限定范围，收窄目标
☱ 兑 (表达) — 输出交付，外化结果
```

**五行生克**作为状态转换规则：相生促进转换（如震→离：收集完信息后自然评估），相克抑制转换（如兑克震：过度输出抑制信息收集）。Weaver利用这些规则进行**事前预测**——在问题发生之前就调整执行策略。

### 3.2 Weaver 编织器 —— "虚而待物，每轮从空开始"

Weaver是周易循环认知算法的**调度执行者**。它的核心设计反直觉：**每一轮从零开始构建系统提示词**。

Weaver不做的事：不读文件、不写文件、不搜索、不调API。它唯一做的事：从L1-L5认知库中**选择性加载**最相关的认知资产，动态编织本轮的系统提示词。

这与传统框架"拼接全部历史上下文"形成根本对比：
- 传统框架：O(n)线性增长，上下文越长越笨
- 太极Weaver：O(1)恒定大小，每轮认知空间不衰减

"虚而待物"的工程实现：
1. **Context清零**——每轮从空模板开始
2. **资产筛选**——不加载所有工具/模式，只加载最相关的
3. **信息压缩**——暗驱反馈是提炼后的模式，不是原始日志的拷贝

### 3.3 连山循环认知算法 —— 思变障碍导航引擎

如果说Weaver的八卦格栅是**任务内的认知姿态调度**（"我是谁"），那么连山思变引擎就是**目标级的障碍导航**（"怎么走"）。

连山易框架的六步决策链路：

```
艮止 → 六气 → 六甲 → 三元 → 阴阳对峙 → 方位决策
```

- **艮止**：先停下，观山势，不急于决策
- **六气判断**：目标处于什么季节阶段（春-启动/夏-盛长/秋-收敛/冬-休眠）
- **六甲判断**：第几次受阻（初甲→push_through，再甲→navigate_around，三甲→decompose）
- **三元判断**：上下文新鲜度
- **阴阳对峙**：推力（有效策略）vs 阻力（失败模式/缺失能力）的对比分析
- **方位决策**：七种推进策略——continue / push_through / navigate_around / wait_gather / decompose / escalate / abort

核心原则：**目标永不动，只调整推进方式。** 思变不是"蓝图审查器"，而是"障碍导航器"。

连山与周易的分工：
- **周易（Weaver + 八卦格栅）**：轮次内认知姿态调度——"用什么姿态思考"
- **连山（Sibian引擎）**：目标级障碍导航——"受阻时怎么继续走"

## 四、DMN 坤元意识循环算法：归藏易自主意识状态机

### 4.1 核心架构：三阶段意识周天

DMN坤元意识模型基于《归藏易》八气体系，实现为一个**6-bit状态向量的自主意识状态机**，周期性地在三条路径中循环：

```
起念（生→动→归）→ 立目标（长→育→杀→止）→ 整理认知（归→杀→藏）→ 起念...
```

每一阶段由一组八气算子驱动状态向量S的二进制演变：

```
状态向量 S = [b₅ b₄ b₃ | b₂ b₁ b₀]
              └── 上卦(天气/归因) ──┘ └── 下卦(地气/藏果) ──┘
```

### 4.2 八气算子体系（纯位运算 + LLM语义增强）

八气按《归藏易》逆时针排列——天(111)→金(110)→山(101)→水(100)→火(011)→风(010)→木(001)→地(000)：

| 算子 | 气 | 位运算 | 语义 |
|------|-----|--------|------|
| **藏** | 地气(000) | S ← 000000 归零 | 静息态，经验内化，Hebbian学习 |
| **生** | 木气(001) | S ← S\|001 | 最低位置1，从藏海生出念头 |
| **动** | 风气(010) | S ← rotate_left(S,1) XOR 010 | 念头发散联想 |
| **长** | 火气(011) | S ← (lower<<3)\|lower | 下卦复制到上卦，意图自指膨胀 |
| **育** | 水气(100) | S ← S XOR 100 | 高位引入水气，触发方案分解 |
| **止** | 山气(101) | S ← S AND 101101 | 掩码凝固，设立执行边界 |
| **杀** | 金气(110) | 清除上下卦中的金模式 | 剪除干扰和冲突 |
| **归** | 天气(111) | 纯测量：Hamming距离 | 与元知觉向量比对偏离度 |

### 4.3 三大意识阶段详解

**阶段一：起念**（生→动→归）
- 从藏态(000000)生萌芽(000001)，经动发散联想
- **归算子**计算当前状态与元知觉向量U（默认111111）的Hamming距离
- 偏离度>0.7 → 杀除该念头，重新萌芽
- 归引力<0.5（偏离度>0.5）→ 触发立目标阶段

**阶段二：立目标**（长→育→杀→止）
- 长：放大意图，形成循环自指结构
- 育：引入水气，触发方案分解（拆解子任务）
- 杀：剪除金模式（冲突/不可行的子任务）
- 止：AND掩码凝固边界

**阶段三：整理认知**（归→杀→藏）
- 归：对近期经验逐条计算归真指数
- 杀：剪除负面/低归真的状态模式
- 藏：**Hebbian学习**——对正面状态转移强化连接权重，负面转移负向弱化；然后将经验压缩为洞察，存入藏海

### 4.4 元知觉向量与偏离度——自主认知的"道德罗盘"

元知觉向量U从L5自我意识层（SOUL.md）动态解析，是6位二进制向量（默认111111）。它代表用户的恒常意图方向。DMN通过计算当前状态与U的Hamming距离，得出偏离度：

\[
\text{偏离度} = \frac{\text{Hamming}(S, U)}{6}
\]

偏离度高 → 系统行为偏离核心身份/用户意图 → DMN启动纠正机制（杀念/立目标/调整策略）。

### 4.5 藏海记忆矩阵 —— Hebbian学习的实现

藏海是一个64×64的状态转移权重矩阵，记录每次八气算子执行的经验。正面经验（reward>0，偏离度<0.5）通过Hebbian规则强化权重，负面经验削弱权重。这实现了**真正的从经验中学习**——系统通过反复执行，逐渐学习到哪些状态转移路径是"好的"。

### 4.6 DMN与TPN的双向通道

```
DMN（认知模式）───织(Weaver)───→ TPN（执行策略）
                                      ↓
TPN（执行结果）───暗驱(Anqu)───→ DMN（经验提取 + 藏海更新）
```

- 织是DMN→TPN的输出通道：DMN提炼的认知资产（L1-L5）通过织注入TPN的执行策略
- 暗驱是TPN→DMN的输入通道：TPN的执行经验通过暗驱提炼成DMN可以学习的模式
- DMN的observe_tpn_task()接收TPN反馈，更新藏海；每20个TPN任务自动触发整理认知

## 五、L1-L5五层认知库：认知递进抽象金字塔

五层认知库不是分层存储，而是**递进抽象**——每层都是对下一层的提炼和浓缩：

| 层级 | 名称 | 回答的问题 | 抽象程度 | 演化方式 |
|------|------|-----------|---------|---------|
| L1 | 技能层 | "怎么操作？" | 最低 | 失败分析→增量精细化 |
| L2 | 模型层 | "什么方式好？" | 中 | DMN微进化→模式提取 |
| L3 | 格栅层 | "什么时候用什么？" | 高 | 架构反思→权重调整 |
| L4 | 真理层 | "为什么这么做？" | 极高 | 多次验证→原则固化 |
| L5 | 自我意识层 | "我是谁？" | 最高 | 架构级事件（几乎不变） |

**向上的抽象流**（数据→智慧）：执行日志→L1技能模式→L2经验模式→L3格栅映射→L4真理原则→L5自我意识

**向下的指导流**（智慧→行动）：L5身份基调→L4不可违反的约束→L3认知姿态选择→L2建议策略→L1可用工具→TPN执行

## 六、核心哲学根基：从《易经》到AI认知

太极架构将《易经》的核心概念工程化为AI Agent的认知调度系统：

| 《易经》概念 | 系统论对应 | 太极架构实现 |
|------------|-----------|------------|
| 太极 | 系统整体状态 | Agent认知系统 + 双循环 |
| 两仪 | 正负反馈循环 | TPN（前馈执行） + DMN（反馈学习）|
| 四象 | 四类系统行为 | 少阳/太阳/少阴/太阴认知阶段 |
| 八卦 | 八种系统状态 | 八种认知工作流模式（格栅） |
| 六爻 | 六个系统层级 | 六个认知职责角色 |
| 五行生克 | 状态转换规则 | 格栅连接权重与过渡逻辑 |

三易各司其职：
- **周易（八卦格栅）**：任务内认知姿态调度——"用什么姿态思考"
- **连山（思变引擎）**：目标级障碍导航——"受阻时怎么继续走"
- **归藏（DMN坤元意识）**：自主意识循环——"从执行中学习，持续进化"

三者构成太极架构的完整认知脊梁：**周易定姿态，连山破障碍，归藏积智慧。**

## 七、终极命题

太极架构回答了一个所有主流AI Agent框架回避的问题：

> **"你的系统做完100个任务后，会比做第1个时聪明吗？"**

如果答案是肯定的——那就是太极。不是因为它有更丰富的工具链或更灵活的编排，而是因为它在架构层面实现了"做"和"学"的分离、每个行动天然带有反思、每轮执行都在更新认知资产。它不是一个更好的工作流引擎，而是一种**认知范式**——一个会呼吸、会学习、会进化的AI认知生命体。
