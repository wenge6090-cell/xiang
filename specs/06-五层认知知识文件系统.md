# 五层认知知识文件系统

**版本：1.0** | **状态：设计完成**

> 藏海向量库是练内功的（训练模型内化），五层认知知识文件是外功（推理时检索注入上下文）。  
> 两者分工清晰：藏海积累经验数据用于微调，知识文件提供外部可检索知识用于武装 LLM。

---

## 〇、五层递进：从数据到智慧

| 层级 | 名称 | 解决的问题 | 文件形式 |
|------|------|-----------|---------|
| L1 | 事实层 | "这件事是什么？" | 结构化词典 (YAML) |
| L2 | 关联层 | "它和别的事有什么关系？" | 关系图谱 (YAML) |
| L3 | 规则层 | "遇到这种情况该怎么办？" | 条件规则集 (Markdown) |
| L4 | 策略层 | "如何思考这个问题？" | 思维框架 (Markdown) |
| L5 | 经验层 | "以前类似的事情是怎么处理的？" | 案例叙事 (Markdown) |

---

## 一、各层详细设计

### L1: 事实层 — 原子化认知

系统对世界最基础的认知，存储不可再分的"事实"。

```yaml
# knowledge/L1_facts/entities.yaml
- name: "三易算法"
  description: "一套用于引导大语言模型认知过程的外部确定性状态机系统。"
  aliases: ["三易", "象语言内核"]
  type: "技术系统"
- name: "归藏"
  description: "三易的核心引擎，基于六位状态向量和八气算子的念头流转机器。"
  parent_system: "三易算法"
```

**检索时机**：生成树 "生"阶段，提取用户问题中的实体，查询相关事实，确保模型理解基本概念。

### L2: 关联层 — 构建思维地图

定义事物之间的逻辑关系，让模型知道知识是如何连接的。

```yaml
# knowledge/L2_relations/tech_relations.yaml
- source: "归藏"
  relation: "是核心组件"
  target: "三易算法"
- source: "连山"
  relation: "在偏离度>0.5时被触发"
  target: "归藏"
  trigger: "偏离度 > 0.5"
```

**检索时机**：生成树 "动"阶段。当思维需要发散时，沿着这些关系边遍历，寻找相关但未明确提及的知识点。

### L3: 规则层 — 启发式经验法则

存储"If-Then"形式的决策规则和禁忌，是连山决策的补充知识源。

```markdown
# knowledge/L3_rules/debugging_rules.md

### 规则：检查模型输出是否偏离
- **IF** 输出内容重复且无新信息 **THEN** 建议启用周易"离"姿态 (温度0.5) 审视
- **IF** 遇到死胡同且受阻次数>=3 **THEN** 建议连山"拆解分解"策略，将问题细化为子任务
- **禁止** 在证据不足时使用"强力突破"策略，除非偏离度<0.3
```

**检索时机**：生成树 "长"阶段和连山介入时。当前策略方向结合这些规则，产出更具体的执行提示。

### L4: 策略层 — 思维框架库

存储标准化的分析框架（如SWOT、第一性原理、5W1H），直接作为"思维脚手架"。

```markdown
# knowledge/L4_strategies/analysis_frameworks.md

### 框架：第一性原理分析
**适用姿态**: 震(启动), 坎(破局)
**步骤**:
1. 拆解问题至最基本要素。
2. 挑战每一个基本假设。
3. 从零开始重构解决方案。
**提示词片段**: "让我们回归问题最基础的事实，逐一审视每个假设..."
```

**检索时机**：周易选择姿态后。根据当前姿态（如坎·破局），检索对应的思维框架，将其作为"育"阶段的结构化提纲注入提示词。

### L5: 经验层 — 案例叙事

存储完整的、高价值的成功或失败案例，提供最直接的参考。

```markdown
# knowledge/L5_experiences/case_studies.md

### 案例：如何处理一个复杂的代码重构
**初始状态**: 偏离度0.6, 受阻次数2, 姿态震
**过程**:
1. 连山触发"迂回绕行"，先写测试覆盖遗留代码。
2. 周易切换至"坤·承载"，稳定执行。
3. 最终偏离度降至0.2，任务成功。
**关键教训**: 面对复杂重构，不要直接"强力突破"，先建立安全网。
```

**检索时机**：任务开始时和连山决策时。当检测到类似初始状态（高偏离度、特定策略），检索匹配案例，将"关键教训"注入上下文。

## 二、文件系统与检索机制

### 目录结构

```
knowledge_base/
├── L1_facts/
├── L2_relations/
├── L3_rules/
├── L4_strategies/
└── L5_experiences/
├── index.json  <-- 元数据索引
└── vectors/    <-- 可选，存放预计算的嵌入向量，用于快速语义搜索
```

### 运行时检索 (RAG)

1. **索引构建**：启动时，后台遍历所有知识文件，提取元数据（标题、标签、适用姿态/策略）存入 index.json。48GB 内存足够把所有文本加载到内存。
2. **多路召回**：结合关键词匹配（针对事实、规则）和嵌入向量相似度（针对策略、经验，由 CPU 上的阴仪小模型实时计算）。
3. **注入提示词**：召回的知识片段被三易主循环编译进系统提示词：

```
[知识注入: L3规则] 当检测到输出重复时，请采用... [知识注入: L5案例] 类似场景下，曾有成功处理方法是...
```

## 三、与三易系统的交互闭环

### 生成时（Skill 使用）

三易系统在合适的算子阶段，通过检索机制从五层知识文件中"拉取"相关知识，武装大语言模型。

| 周天阶段 | 检索层 | 用途 |
|---------|--------|------|
| 生（起念） | L1 事实层 | 理解基本概念和实体 |
| 动（发散） | L2 关联层 | 沿关系图扩展视野 |
| 长（聚焦）+ 连山介入 | L3 规则层 | 提供决策规则约束 |
| 育（分解）+ 周易选姿态 | L4 策略层 | 提供思维框架 |
| 任务开始 + 连山决策 | L5 经验层 | 提供历史案例参考 |

### 压缩时（知识沉淀）

在压缩树的 "藏"阶段，如果某个任务的最终结果获得了高奖励（Reward > 0.8），系统生成"知识沉淀摘要"：

- 一个新案例 → 加入 L5 经验层
- 一条新规则 → 加入 L3 规则层
- 一个新实体 → 加入 L1 事实层

摘要暂存，待人工审核后正式并入知识文件。对自主运行阶段，可设置自动批准阈值。

### 训练时（内功修炼）

定期将新增的高质量知识文件条目，转化为指令微调的训练样本：

- L4 框架和 L5 案例 → QA 训练对
- 用新样本微调模型 → 把"外功"逐渐转化为"内功"

## 四、起步路线

1. **手动创建种子知识**：为你的核心任务领域，手动创建 5-10 个 L1 实体、5 条 L3 规则、2 个 L4 框架、1 个 L5 案例。这构成系统的"先天知识"。
2. **实现简易检索器**：先用关键词匹配和文件名索引。L4/L5 这类长文本，可用轻量嵌入模型在 CPU 上做语义检索。
3. **接入三易循环**：在生成树的对应位置添加"知识检索钩子"，将检索结果注入提示词。
4. **启动沉淀循环**：在压缩树的藏阶段添加"知识沉淀"逻辑，让运行中产生的经验自动反馈回知识文件。

## 五、与藏海向量库的分工

| 维度 | 藏海向量库 | 五层知识文件 |
|------|-----------|------------|
| **用途** | 训练模型内化能力 | 推理时检索注入上下文 |
| **数据类型** | (状态,策略,结果,奖励) 经验向量 | 结构化知识（事实/规则/框架/案例） |
| **更新方式** | 每轮周天自动写入 | 高奖励任务触发沉淀 + 人工审核 |
| **检索方式** | 语义向量相似度 | 关键词 + 嵌入向量多路召回 |
| **存续性** | 与模型生命周期绑定 | 独立于模型，可跨模型复用 |
| **目标** | 让模型"本能"变强 | 让模型临时"想起来" |

---

> 藏海向量库练内功，五层知识文件练外功。内外兼修，方为完整的认知生命体。
