# 草稿：归藏生成树闭环 — 观测层与执行层接线

## 需求确认

**用户目标**：完成归藏的生成树闭环，使生→动→长→育的四个阶段真正可观测、可执行。

**两个关键管道断点**：
1. 观测层（归+HanziMap/EmbeddingObserver）—— 未接入 CangVM，永远为 None
2. 执行层（杀/止/藏的上下文操作）—— 杀/止/藏只改 Gua 位，不管理对话历史和 KV cache

## 技术决策（已确认）

- 生成树 = 生→动→长→育 = 意识阶段的离散可读标签
- 观测层 = 归（偏离度）+ HanziMap（汉字投影轨迹）= LLM 内部状态的符号快照
- 执行层 = 杀/止/藏 = 上下文管理器（对话历史裁剪 + KV cache 管理）
- 压缩树 = 纯粹的上下文管理器，不做语义判断
- 所有文档、注释、代码文件使用中文

## 范围边界

- **INCLUDE**：
  - xiang-core: EmbeddingObserver/HanziMap 管道确认
  - xiang-cangvm: 杀/止/藏新增上下文信号输出
  - xiang-chat: ConstrainedEngine 注入观察器和执行上下文操作
  - xiang-llm: KV cache snapshot/rollback 实现（基于 seq_id）
  - 安装文档、架构文档更新
- **EXCLUDE**：
  - 路线B LoRA 微调
  - 路线C 双 LLM
  - VLM 视觉映射
  - 五层认知知识文件系统
  - 汉字嵌入数据导出（属于另一项工作，与导出脚本相关）
